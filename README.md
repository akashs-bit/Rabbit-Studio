## 🚀 Features

* 🔐 **Authentication & Security:** Secure User Signup/Login with JWT-based encryption & Email OTP verification workflow.
* 👥 **User Administration:** Admin capability to view and manage registered user accounts.
* 📦 **Product Management:** Complete CRUD operations for handling inventory and products.
* 🛡️ **Protected Routes:** Custom authorization middleware guarding sensitive API routes and pages.
* 📱 **Responsive UI:** Clean, modern, mobile-first design optimized for all viewports with smooth animations.

---

## 🛠 Tech Stack

### Frontend
* **Core Framework:** React.js (Vite)
* **Styling:** CSS / Tailwind CSS
* **Navigation:** React Router DOM
* **HTTP Client:** Axios

### Backend
* **Runtime Environment:** Node.js & Express.js
* **Database:** MongoDB Atlas (Mongoose ODM)
* **Security & Auth:** JWT, bcryptjs, & CORS configuration

## ⚙️ Installation & Setup

```bash
# Clone the repository
git clone [https://github.com/AkashBojja/rabbit-studio.git](https://github.com/AkashBojja/rabbit-studio.git)

# Start Frontend
cd frontend
npm install
npm run dev

# Start Backend (in a new terminal)
cd ../backend
npm install
npm run dev
